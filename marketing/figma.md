# Konversa — Sistema de diseño en Figma

Archivo de Figma (editable): **Konversa — Brand System**
🔗 https://www.figma.com/design/VptMMYWJQyeC077ROlIZ1K

## Contenido del archivo

### Página "Brand"
- Logo (isotipo + lockup) con gradiente de marca.
- Paleta de color (esmeraldas, neutros) + colores de estado del pipeline.
- Escala tipográfica (Inter).

### Página "Instagram"
4 plantillas nativas y editables (mismas piezas que `instagram/piezas/`, pero modificables):
- `IG-01-Lanzamiento` — 1080×1350 (gradiente)
- `IG-02-Feature-QR` — 1080×1350 (claro)
- `IG-03-Diferenciador` — 1080×1080 (oscuro)
- `IG-04-Tres-pasos` — 1080×1080 (claro)

## Cómo exportar las piezas
1. Abrí el archivo en Figma.
2. Seleccioná el frame que querés (ej. `IG-01-Lanzamiento`).
3. Panel derecho → sección **Export** → `+` → formato **PNG** (2x para alta resolución).
4. Botón **Export**.

> También podés exportar todos los frames juntos: seleccioná varios y exportá, o
> usá `File → Export frames to PDF` para un set rápido.

## Cómo crear una pieza nueva (rápido)
- Duplicá un frame existente (Ctrl/Cmd+D), cambiá los textos y, si aplica, la captura.
- Mantené la grilla y los estilos de marca (colores y tipografías de la página "Brand").

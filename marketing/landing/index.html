Preguntas frecuentes

¿Necesito conocimientos técnicos?

No. Escaneás un QR con tu WhatsApp y empezás a usarlo. El setup tarda alrededor de un minuto.

¿Tiene costos por mensaje?

No. Konversa usa tu propio número de WhatsApp directamente, sin la API oficial, así que no pagás por mensaje.

¿Es seguro para mi número?

Konversa usa una conexión no oficial (estilo WhatsApp Web). Está pensado para organizar tu atención y tus ventas, no para envíos masivos. Recomendamos un uso responsable, sin spam, para cuidar tu cuenta.

¿Mis datos quedan guardados?

Sí. Tus contactos, conversaciones y la calificación de cada cliente quedan guardados de forma segura para que no pierdas el historial.
